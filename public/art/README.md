# Art

Drop PNG files here with these names, and the game uses them in place of its stand-in colors. Nothing else needs changing.

## Floors: `floors/`, 528 × 528

There's one outdoor and one indoor floor for each sector. An indoor floor can be one shared interior, altered a little for each sector.

| Sector | Outdoor | Indoor |
|---|---|---|
| city | `city-outdoor.png` | `city-indoor.png` |
| forest | `forest-outdoor.png` | `forest-indoor.png` |
| swamp | `swamp-outdoor.png` | `swamp-indoor.png` |
| mountain | `mountain-outdoor.png` | `mountain-indoor.png` |
| hill | `hill-outdoor.png` | `hill-indoor.png` |
| plains | `plains-outdoor.png` | `plains-indoor.png` |

## Walls: `walls/`, a 32 × 32 tile that repeats seamlessly

The game repeats the tile along each wall. Taller walls are drawn thicker, from about 6 to 22 pixels.

`stone.png`, `brick.png`, `wood.png`, `rock.png`, `hedge.png`, `palisade.png`
